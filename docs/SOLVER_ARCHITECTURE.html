Helmholtz Solver Architecture

完整物理与矩阵组装推导见 ACOUSTIC_PHYSICS_DERIVATION.html；边界凝聚数学原理见 BOUNDARY_CONDENSATION.html；纯相位训练见 PHASE_ONLY_TRAINING.html；精简版离散说明见 HELMHOLTZ_DISCRETIZATION.html。

固定矩阵、相位相关右端

在网格、障碍物、介质、频率和边界条件固定时，系统写为：

\[ A u(\phi) = b(\phi) \]

相位只出现在换能器 Dirichlet 右端中。定义 \(B\) 的第 \(r\) 列为第 \(r\) 个阵元在零相位时的边界激励，则：

\[ b(\phi) = B w(\phi), \qquad w_r(\phi) = e^{i\phi_r} \]

因此工程流程分成两个阶段：

  1. 首次调用：Warp 装配 \(A\)，求解器执行 analysis 和 factorization。
  2. 后续调用：只更新 \(b(\phi)\)；高性能后端同时复用直接分解因子。

首次矩阵装配同时缓存底面阵元映射。后续相位更新由 WarpAssemblyEngine.assemble_rhs() 直接在有效 Dirichlet 点上用 NumPy complex128 生成复数 RHS，不再遍历整个体网格。

精确边界静态凝聚

完整块分解证明、稀疏传递矩阵构造和同因子伴随推导见 BOUNDARY_CONDENSATION.html。

BoundaryCondensedDirectSolver 负责该步骤。原始矩阵由于 Dirichlet 单位行和 Sommerfeld 单边行不是对称矩阵，但所有保留的内部及 reflecting stencil 都是复对称的。把未知量分为保留自由度 \(R\) 和待消去边界自由度 \(E\)：

\[ \begin{bmatrix} A_{RR} & A_{RE} \\ A_{ER} & A_{EE} \end{bmatrix} \begin{bmatrix} u_R \\ u_E \end{bmatrix} = \begin{bmatrix} b_R \\ b_E \end{bmatrix} \]

精确消去边界变量：

\[ S = A_{RR} - A_{RE}A_{EE}^{-1}A_{ER} \] \[ \widehat b_R = b_R - A_{RE}A_{EE}^{-1}b_E \]

当前边界行最多依赖一个向内邻居，因此齐次边界传递矩阵

\[ T = -A_{EE}^{-1}A_{ER} \]

每行最多只有一个非零元，可以沿边界依赖链精确构造，不需要形成稠密逆矩阵。于是：

\[ S = A_{RR} + A_{RE}T \]

每次构建都会验证 \(S=S^T\)。验证通过后只把 \(S\) 的下三角交给 cuDSS 复对称分解。求解后通过：

\[ u_E = A_{EE}^{-1}b_E + T u_R \]

恢复完整空间声场。该过程是原始线性系统的精确块高斯消元，没有修改 PDE、障碍物、边界条件或解的定义。

cuDSS 自动内存模式

CuDSSHybridSymmetricSolver 在 numerical factorization 之前读取 cuDSS symbolic analysis 返回的内存估算：

  • peak_device_memory：hybrid execute 的 GPU 峰值。
  • hybrid_min_device_memory：hybrid memory mode 的最低 GPU 需求。
  • peak_host_memory：hybrid memory mode 的主存因子需求。

hybrid_execution_mode: "auto" 的选择规则为：

这里的 auto 只在高性能后端内部选择显存执行模式，不是第四种线性求解器。

if hybrid-execute peak <= GPU budget:
    use hybrid execute
elif HMM minimum <= GPU budget:
    re-plan with hybrid memory mode
else:
    stop before numerical factorization with a memory report

GPU budget 同时受配置上限、当前空闲显存和预留空间约束：

\[ M_{\mathrm{budget}} = \min\left( M_{\mathrm{config}}, M_{\mathrm{free}} - M_{\mathrm{reserve}} \right) \] 
hybrid_execution_mode: "auto"
hybrid_device_memory_limit_gb: 5.6
hybrid_device_memory_reserve_gb: 0.75
hybrid_register_cuda_memory: false

前向与伴随

前向求解为：

\[ A u = b \]

伴随求解为：

\[ A^H \lambda = q \]

高性能凝聚后端利用 \(S^T=S\)，因此：

\[ S^H = \overline{S} \] \[ S^H y = r \quad\Longleftrightarrow\quad S\overline{y} = \overline{r} \]

所以伴随约化系统通过“共轭 RHS、使用同一因子求解、共轭结果”完成，再对 \(A_{EE}^H\) 做边界回代。前向和伴随不再各保存一份大型 cuDSS 因子。

实测结果

测试设备为 NVIDIA GeForce RTX 4070 Laptop GPU 8 GiB，数值类型为 complex128。

网格 后端/模式 首次前向 复用前向 结果
\(31^3\) 凝聚复对称 + hybrid execute 0.47 s 6.1 ms 前向残差 \(6.53\times10^{-9}\)，伴随 8.3 ms，残差 \(1.43\times10^{-14}\)。
\(61^3\) 凝聚复对称 + hybrid execute 6.85 s 46.5 ms 前向残差 \(9.09\times10^{-7}\)，伴随 61 ms，残差 \(7.02\times10^{-13}\)。
\(81^3\) 凝聚复对称 通过 symbolic 显存预检 因子可复用 显存需求低于未凝聚的一般 LU；\(108^3\) 已覆盖更大规模验证。
\(108^3\) 凝聚复对称 + hybrid memory 427.33 s 14.10 s 前向残差 \(2.69\times10^{-6}\)，伴随 8.15 s，残差 \(3.36\times10^{-12}\)。

在 \(108^3\) 上，一般非对称 LU 的 HMM 最低显存约为 9.91 GiB；精确边界凝聚后的复对称分解将最低值降至约 5.46 GiB。当前配置把 cuDSS 显存限制为 5.6 GiB，实测完成了 numerical factorization、两次前向和一次伴随。

\(108^3\) 的约化因子仍需要约 18.63 GiB 主存。测试时其他应用占用了大量物理内存，Windows 发生页面交换，因此首次 427 秒主要受主存压力影响。运行大规模分解前关闭高内存应用，或者增加系统内存，可明显改善首次 factorization/solve 时间。
