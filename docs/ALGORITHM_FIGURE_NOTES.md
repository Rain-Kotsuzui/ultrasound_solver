## 申报材料图注

**图 2. 复杂环境下超声阵列声场调控的算法架构与相位优化流程。** 系统将阵列参数、障碍物几何和边界条件转化为三维 Helmholtz 离散系统，通过边界凝聚与 GPU 稀疏直接求解构建全场响应基。在场景固定时，利用响应基完成声场合成和梯度回传，迭代优化阵元相位，实现目标振幅匹配、焦点增强或旁瓣抑制，并在同一场景模型下与传统几何相位进行对照。

## 阅读顺序

1. **场景输入与建模**：标定换能器幅值，确定阵元位置、求解网格和六面边界；将闭合 Mesh 采样为 SDF，再插值得到密度与声速场。
2. **离线响应基构建**：装配矩阵 A 和阵元激励 B，检查缓存；需要构建时，进行边界凝聚、一次分解和多右端回代，得到 G。
3. **训练准备**：构造目标振幅与权重、目标采样索引和旁瓣掩码，选择初相位，按开关执行有限差分诊断和传统相位对照。
4. **在线优化**：沿图中绿色回路读取，第一行从左到右，第二行从右到左；更新相位后重新评估声场，直到优化器终止。
5. **结果输出**：保存最终相位、复声场、振幅与历史；以相同响应基评估传统方法，进行交互式可视化。

G 是训练期间共享的固定数据，供初始化、声场合成、VJP 和传统方法对照使用；图中只绘制主要依赖线，避免共享数据连线贯穿所有节点。

## 公式与实现口径

### 前向模型

令 N 为全部网格自由度数，M 为阵元数：

```text
A ∈ C^(N×N)
B, G ∈ C^(N×M)
φ ∈ R^M
G = A^(-1) B
w = exp(iφ)
u = G w
a = |u|
```

求逆符号是数学记法，代码通过线性求解构建 G，并不显式生成 A 的逆矩阵。G 是完整离散场景的响应，不是自由空间近似，也不是神经网络。

### 三种损失

```text
field_match:
L = 1/2 Σ_j [W_j (a_j - a*_j)]²

focal_pressure:
L = -α/K Σ_k a[t_k] + β/(2N) Σ_j a_j²

focal_contrast:
L = -α/K Σ_k a[t_k] + β smax_T(a_Ω)

smax_T(a_Ω) = T log[(1/|Ω|) Σ_(j∈Ω) exp(a_j/T)]
```

α 与 β 分别对应 focal 类损失的 `target_weight` 与 `background_weight`；`field_match` 使用生成或加载的权重场 W，且权重在平方损失内，因此导数包含 W²。

`focal_pressure` 的能量项覆盖全场，并非只覆盖目标之外。`focal_contrast` 的 Ω 才会排除目标邻域及指定源面层。代码通过减去最大振幅计算稳定的 log-sum-exp；它不是直接最小化振幅比值，也不保证目标振幅一定超过所有旁瓣。

### 复数导数与相位 VJP

图中 q 表示 cotangent，避免与声速 c 混淆：

```text
dL = Re(q^H du)

field_match:
q = W² ⊙ (a - a*) ⊙ u/(a + ε)

focal_pressure:
目标采样点累加 -α/K · u/(a + ε)
全场累加 β/N · u

focal_contrast:
目标采样点累加 -α/K · u/(a + ε)
背景区域累加 β · softmax(a_Ω/T) ⊙ u_Ω/(a_Ω + ε)

z = G^H q
∇φ L = Re[conj(z) ⊙ i exp(iφ)]
```

上述除法和乘法按元素执行。幅值在零点不可微；当前实现使用 `ε=1e-12` 稳定分母，其 cotangent 是数值稳定处理，并不是改用平滑幅值损失后的严格导数。

与 PDE 伴随的关系：

```text
A^H λ = q
G^H q = B^H A^(-H) q = B^H λ
```

固定场景下，G 的预计算使在线回传不必再显式求解伴随 PDE。若优化障碍物或材料，A 随参数变化，则不能复用同一个 G；这不属于图中的已实现训练闭环。

### 诊断、停止与对照

- 梯度检查默认比较前 `min(8, M)` 个阵元；输出绝对误差与 `误差 / max(|解析梯度|, |差分梯度|, 1)`，不是纯相对误差；当前只打印，不自动设置通过门槛。
- L-BFGS-B 可能因收敛、迭代上限或线搜索等状态终止；Adam 按指定步数运行。图中“结束”不等于已经达到全局最优。
- 当前输出的是优化器最终相位，代码没有独立的最优历史检查点选择流程。
- `compare_geometric` 在优化前计算几何相位的实际模型响应，最终用于对照；不是把自由空间振幅直接与障碍物场比较。
- 图中对比度 `mean(a_target)/max(a_background)` 对应 `focal_contrast` 的统计口径，不能直接套用到另外两种 loss 的日志。
- 当目标或损失变化、物理场景未变时可复用 G；场景指纹不匹配会报错，不会自动覆盖旧响应基。
