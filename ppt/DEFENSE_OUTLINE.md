# HaptiField 五分钟答辩大纲

## 核心叙事

可编程空气超声能够形成非接触触觉、空间图案和声悬浮。真实场景中的障碍物、反射面与材料变化会重塑传播路径，因此相位设计需要从几何距离计算走向完整三维物理场优化。

本项目建立了从场景几何、Helmholtz 求解、解析相位梯度到 SonicSurface 实物阵列的完整链路。

## 背景与价值

空气超声相控阵通过控制阵元的相位和幅值形成空间压力分布，已经用于：

- XR / 元宇宙中的虚拟对象触觉。
- 遥操作中的远端接触反馈与临场感增强。
- 医疗、洁净空间和公共终端中的无菌交互。
- 空间引导、无障碍提示和操作导航。
- 多焦点、轨迹和体积显示。
- 声悬浮、微粒操控与定向声场。

代表工作：

- Hoshi et al., 2010：非接触超声触觉，DOI `10.1109/TOH.2010.4`。
- Martinez Plasencia et al., 2020：GS-PAT，DOI `10.1145/3386569.3392492`。
- Fushimi et al., 2021：Diff-PAT，DOI `10.1038/s41598-021-91880-2`。
- Rakkolainen et al., 2021：中空超声触觉综述，DOI `10.1109/TOH.2020.3018754`。

## 真实环境问题

```text
自由空间相位补偿描述直达路径；
真实环境还包含反射、透射、吸收与边缘衍射。
传播路径改变后，最优相位也随之改变。
```

相关工作：

- Hirayama et al., 2022：任意静态散射体中的高速声学全息，DOI `10.1126/sciadv.abn7614`。
- Chen et al., 2023：障碍物环境中的声压场重建，DOI `10.1109/TOH.2023.3309975`。
- Mukherjee et al., 2025：手部散射建模与触觉感知，DOI `10.1145/3706599.3720287`。

本项目选择“已知几何与材料”的路线，用 SDF 和异质三维 Helmholtz 方程预测完整声场，再直接优化阵元相位。

## 方法讲解顺序

### 三维求解器

```text
Mesh / SDF
→ 平滑密度与声速场
→ 七点有限差分
→ 边界凝聚
→ cuDSS 复对称直接求解
```

边界凝聚同时缩小分解系统并恢复复对称结构；固定场景的分解因子可供多个右端复用。

### 响应基

```text
B：阵元到网格右端的稀疏映射
G：每个阵元经过完整 PDE 传播后的全场响应
```

公式：

```text
A[g₁,...,gM] = [b₁,...,bM]
u(φ) = G exp(iφ)
```

`G=A⁻¹B` 表示多右端求解。当前 256 个右端按每批 16 列构造，共享同一次矩阵分解。

### 复声场梯度 c

```text
uⱼ = xⱼ + i yⱼ
cⱼ = ∂L/∂xⱼ + i ∂L/∂yⱼ
dL = Re(cᴴdu)
```

c 是 loss 对完整复声场的敏感度。对于振幅损失，残差决定增减方向，`u/|u|` 保留复声压方向。

### VJP

```text
∂u/∂φᵣ = i G[:,r] exp(iφᵣ)
z = Gᴴc
∇φL = Re(conj(z) ⊙ i exp(iφ))
```

VJP 是向量与 Jacobian 的乘法过程。它直接计算 Jacobian 的反向作用，输出 256 维实数相位梯度。

## COMSOL 交叉验证

项目求解器与 COMSOL 使用相同的几何、材料、边界条件和阵元相位独立计算：

- `extended` 包含 6 种障碍物形状和 2 种边界条件，共 12 个正演算例。
- 顶部振幅空间相关为 `0.596–0.733`。
- `phase_study` 包含平板与块体场景，以及 same、geometric、response、adjoint 四种相位。
- 两套求解器的目标对比度跨方法 Pearson 相关为 `0.881`。
- COMSOL 对优化相位复现 `7.46–13.23 dB` 的目标均值增益。

讲述重点：

```text
两种独立离散与求解链路都预测到目标增强，
并对强调目标/背景分离的 adjoint 相位给出一致趋势。
```

## 数值证据

声场对比使用归档的 12×12、41³、+x 反射场景：

- 几何相位目标点声压：约 571 Pa。
- 解析梯度优化目标点声压：约 3380 Pa。
- 目标声压提升约 5.9 倍。
- 目标/背景峰值比：0.31 → 2.81，提升约 9.2 倍。

算法比较采用首次达到共同 loss 门槛的时间与场评估次数。门槛 `−1593.498` 下：

- Adjoint + Adam：1.46 s / 89 次。
- CMA-ES：29.30 s / 5762 次。
- L-SHADE：41.44 s / 9453 次。

更新器消融固定相同响应基、解析 VJP、初始相位和损失；Adam 在 `−1860` 门槛下最早达标。

## 实物系统
