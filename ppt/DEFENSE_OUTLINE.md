# 五分钟答辩大纲

## 目标

用五分钟说明项目从物理建模、可微相位优化、数值交叉验证到硬件部署的完整路线。答辩核心不是展示“能聚焦”，而是说明在障碍物和反射边界存在时，仍能通过真实三维声场获得可解释、可优化、可部署的相位解。

当前扩展为八页，讲述时长合计仍为 4 分 35 秒，预留 25 秒现场缓冲。

为完整展示既有 Loss 曲线，原“算法比较与消融”拆为三页；效果页改为用户后续填图。以下编排与 `index.html` 同步，优先于后文原六部分的页号和时间：

| --- | --- | --- |
| 1 | 问题与主张 | 20 秒 |

两张 Loss 图使用归档完整原图：横轴均为场评估次数；实线为滑动中位数，虚线为历史最优，浅线为原始损失。不是跨种子均值或置信区间。

效果页暂不放归档几何相位图充当用户要展示的新 baseline。待用户提供准确方法名与图片后，通过 `media.js` 填入；两组相位需在同一个含障碍物场景中评估，使用相同切面、坐标、单位与色标。COMSOL 独立交叉验证说明保留，但不能把方法间效果对比当作求解器误差验证。

## 叙事原则

- 先讲问题，再讲方法，再讲证据，最后讲部署。
- 每页只保留一个主结论和一个主视觉。
- 不将未完成的硬件标定或实测声场描述为已完成闭环。
- 不将 12 x 12 原型实验的效率数据伪装为当前 16 x 16 硬件结果。
- COMSOL 用于独立物理交叉验证；没有误差图或统计值时，不使用“精确一致”等超出证据范围的表述。

## 原六部分内容说明

### 1. 问题与主张

**时间：25 秒**

**标题建议**

```text
复杂边界下，几何相位不再保证聚焦
```

**内容**

- 障碍物、介质变化和反射边界会改变传播路径、干涉结构与旁瓣分布。
- 目标是在固定真实场景中，仅优化阵元相位，使目标区域聚焦并压制旁瓣。
- 项目主张：以完整三维物理场作为优化约束，而不是仅根据阵元到目标点的几何距离计算相位。

**主视觉**

- 一张包含阵列、障碍物、反射边界、焦点和旁瓣的二维剖面图。

**讲述重点**

```text
我们解决的不是自由场聚焦，而是复杂边界下的真实声场调控。
```

### 2. 三维 Helmholtz 求解器

**时间：50 秒**

**标题建议**

```text
将真实场景转化为可求解的三维复声压场
```

**内容**

- 三维变参数 Helmholtz 方程。
- `Mesh -> SDF -> 平滑材料插值`，将障碍物几何映射为材料参数。
- 7 点 stencil 离散。
- 阵面 Dirichlet 激励、Sommerfeld 开放边界、刚性反射边界。
- 边界凝聚直接法和 GPU 求解后端，用于降低大规模求解开销。

**核心公式**

```text
∇·(ρ^(-1) ∇u) + ω²(ρc²)^(-1)u = 0
```

**讲述重点**

```text
优化器看到的是障碍物、介质和边界共同作用后的复声压场。
```

### 3. 响应基与伴随梯度

**时间：65 秒**

**标题建议**

```text
一次 VJP 得到全部阵元相位的解析梯度
```

**内容**

- 固定场景后，建立阵元相位响应基：

```text
u(φ) = G exp(iφ)
```

- 离线构建响应基，在线迭代直接合成完整三维声场。
- 使用 `focal_contrast`，同时提高目标区域振幅并压制背景最大旁瓣。
- 从损失对复场的导数出发，使用 VJP/伴随法获得全部相位变量梯度。
- 默认更新器采用 Adam；Adam 不是核心创新，核心创新是解析物理梯度。

**核心公式**

按代码中的复场 cotangent 约定定义 `g`，避免 Wirtinger 导数的系数约定歧义：

```text
dL = Re(gᴴ du)
z = exp(iφ)
q = Gᴴ g
∂L / ∂φ = Re(conj(q) ⊙ i z)
          = Im(conj(z) ⊙ q)
```

这里最后一式的符号是正号。与 PDE 伴随系统 `Aᴴλ = g`、`q = Bᴴλ` 等价；实际响应基优化内环直接计算 `Gᴴg`，不需要每步重新求解 PDE。

**讲述重点**

```text
有限差分需要按变量数重复计算；伴随法将一个损失对全部相位的导数压缩为一次反向传播。
```

### 4. 数值验证

**时间：35 秒**

**标题建议**

```text
以 COMSOL 作为独立物理交叉验证
```

**内容**

- 在相同阵列、几何、材料、边界和激励下建立 COMSOL 模型。
- 对比切面声压分布、焦点位置、反射结构和旁瓣趋势。
- 使用多保真路线：低分辨率搜索相位，高分辨率与 COMSOL 验证物理结论。

**需要放入的真实证据**

- 自研求解器与 COMSOL 的同切面声压图。
- 误差图、相关系数或焦点位置偏差之一。

**讲述重点**

```text
COMSOL 的角色是独立验证物理模型，不是替代优化器。
```

### 5. 算法比较与优化器消融

**时间：65 秒**

**标题建议**

```text
解析梯度在共同质量门槛下更高效
```

**内容分为两部分**

#### 算法比较

- 固定同一物理场景、初始相位、响应基、目标和时间预算。
- 主指标不使用“算法停止时总耗时”，而是首次达到共同质量门槛所需：
  - 墙钟时间。
  - 场评估次数。
- 共同门槛：
  - `-1593.498`
  - `-1800`
  - `-1860`

**已有 12 x 12 原型数据**

| 算法 | 达到 `-1593.498` | 达到 `-1800` | 达到 `-1860` |
| --- | --- | --- | --- |
| Adjoint + Adam | 1.46 s / 89 次 | 2.00 s / 163 次 | 3.44 s / 350 次 |
| CMA-ES | 29.30 s / 5762 次 | 未达到 | 未达到 |
| L-SHADE | 41.44 s / 9453 次 | 未达到 | 未达到 |

#### 优化器消融

- 固定同一响应基、解析 VJP、初始相位和损失，仅替换更新规则。
- 用于证明性能收益不来自 L-BFGS-B 的偶然选择。

| 更新器 | 达到 `-1860` 的结果 | 结论 |
| --- | --- | --- |
| Adam | 2.69 s / 350 次 | 默认更新器 |
| AdamW | 2.93 s / 350 次 | 接近 Adam |
| Lion | 3.35 s / 457 次 | 可用但较慢 |
| Nonlinear CG | 21.14 s / 2957 次 | 线搜索更敏感 |
| L-BFGS-B | 未达到 | 不是性能来源 |

**表述限制**

- 上述数据来自归档的 12 x 12 原型统一场景。
- 它们用于说明解析梯度的优化机制。
- 当前 16 x 16 部署场景应在硬件标定后重新报告最终效率指标。

**讲述重点**

```text
比较的是达到同一质量所需的代价，而不是谁在严格停滞确认前花的总时间更短。
```

### 6. 16 x 16 阵列与部署结论

**时间：35 秒**

**标题建议**

```text
从数值相位到可验证的实物声场
```

- 当前部署规模为 16 x 16，共 256 通道。
- 使用 AcousticField/Ultraino 完成阵元坐标、通道顺序和逐阵元相位标定。
- 优化输出的连续相位经过通道映射、标定偏置和 32 档量化后下发。
- 本地 S/C 服务隔离优化进程和串口控制。

**部署链路**

```text

  -> 通道映射
  -> 相位标定偏置
  -> 32 档量化
  -> Ultraino SimpleFPGA 协议

  -> 实测声场
```

**状态表述**

```text
硬件平台、标定工具和下发接口已具备；
逐阵元标定与实测闭环验证正在进行。
```

```text
完成从三维物理建模、解析相位优化、独立数值验证到硬件部署接口的完整技术路线。
```

## 专业图表规范

### 算法比较

- 每个质量门槛单独比较，不混合不同门槛。
- 时间与场评估次数分别展示，或用二维散点图展示。
- 未达到门槛必须写为 `not reached`，不能使用时间上限或停止时 loss 替代。
- `response_alignment` 应作为解析初始化基线，不应与完整迭代优化器混为同一类竞争对象。

### 消融实验

- 图表标题必须说明“同一解析梯度，仅替换更新器”。
- 重点展示高质量门槛的首次达到时间与评估数。
- 不使用各算法最终停止时间作为主效率结论。

## 视觉方向

- 采用科学编辑设计：清晰网格、严格对齐、少量高对比强调色。
- 参考 Josef Müller-Brockmann 的信息层级，但网格只服务排版，不作为装饰性背景。
- 建议颜色：冷白底、石墨黑文字、钴蓝表示物理前向、朱红表示目标/误差、深绿表示梯度回传。
- 每页一个主图：物理剖面、求解器流程、梯度回传、COMSOL 对照、专业图表或硬件链路。
- 禁止渐变、玻璃拟态、悬浮卡片堆叠和装饰性 AI 图案。

## 开始制作前需要补齐的素材

1. COMSOL 与自研求解器的实际对照图，最好包含误差图或误差指标。
2. 16 x 16 实物阵列照片。
3. 标定过程照片或相位检测器照片。
4. 标定后的实测焦点图、声压扫描图或可见的聚焦验证材料。

在缺少上述素材时，可以制作“算法与数值验证阶段”的答辩稿，但不能将其包装为完成实物闭环的最终答辩稿。
