09 响应基如何构建02 / 建模与算法

一次分解，构建完整响应基。

G = A⁻¹B 是 256 个线性方程解的紧凑写法。

传播算子 A∈ℂN×N

几何、材料与边界条件决定；固定场景下保持不变。

阵元激励 B=Cdiag(P)

第 r 列 bᵣ 只在阵元 r 覆盖的底面网格点非零。

完整响应 G=[g1,…,gM]

第 r 列 gᵣ 是该阵元单独激励得到的完整三维声场。

A[g1,…,gM]=[b1,…,bM] 等价于逐列求解 Agr=br
1装配并凝聚 A
2cuDSS 分解一次
3每批构造 16 列 RHS
4复用因子求满 256 列
当前规模55³ 网格 · 256 阵元
计算方式求解 AG = B
在线阶段u = G exp(iφ)
完整 G：166,375 × 256；B 按批临时构造，场景不变即可复用。09 / 17
10 复声场梯度 c02 / 建模与算法

先在实数域求导，再合并成复向量。

c 汇总 loss 对每个网格点声压实部与虚部的敏感度。

严格定义 uj=xj+iyj cj=∂L∂xj+i∂L∂yj dL=Re(cHdu)

这与在 2N 维实数空间中分别对实部、虚部求导完全等价。

振幅 loss 的实例 Lj=12Wj2(|uj|−aj*)2 cj=Wj2(|uj|−aj*)uj|uj|+ε

Wⱼ 决定关注位置；残差决定增减方向；uⱼ / |uⱼ| 保留复声压方向。

把 c 想成“虚拟伴随声源”

目标点需要增强时产生负向敏感度，旁瓣区域需要抑制时产生正向敏感度；loss 区域外的点直接贡献为 0。

输入复声场 u，长度 N
逐点求导得到复向量 c，长度 N
数值正则ε 平滑零振幅邻域
复数表示压缩了两组实梯度，链式法则保持不变。10 / 17
11 VJP 与相位梯度02 / 建模与算法

一次反传，得到全部相位梯度。

VJP 将全场敏感度直接投影到 256 个相位变量。

1 / 相位改变声场 u=Gexp(iφ) ∂u∂φr=iG:,reiφr

第 r 个相位只旋转响应基的第 r 列。

2 / 全场敏感度反投影 z=GHc

zᵣ = G[:,r]ᴴc：把所有网格点对 loss 的影响汇总到阵元 r。

3 / 读取实数相位梯度 ∂L∂φr=Re[zr¯ieiφr]

取实部后，每个阵元得到一个可直接用于优化的实数。

向量形式 ∇φL=Re[z¯⊙iexp(iφ)]

⊙ 表示逐元素乘法
H 表示共轭转置
VJP = Vector–Jacobian Product

完整 JacobianJ = ∂u/∂φ，形状 N × M

VJP 直接计算其反向作用。

解析 VJPGᴴc + 逐元素链式法则

一次反向矩阵向量乘得到 256 个梯度。

PDE 伴随等价式Aᴴλ = c，Gᴴc = Bᴴλ

固定场景用预计算 G 完成在线反传。

一次 Gᴴc 汇总全部网格敏感度，输出 256 维实数梯度。11 / 17
