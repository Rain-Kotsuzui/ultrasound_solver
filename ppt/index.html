03 响应基与伴随梯度前向合成 / 反向传播

一次反向传播，得到全部相位梯度。

场景固定时，非线性只留在相位参数与目标函数中。

预计算G=A−1B

B 为单位阵元激励矩阵；几何、材料、边界不变时复用 G。

前向 / 相位 → 声场 → 目标
z=eiφu=Gz

聚焦增强，旁瓣抑制

L=−α|u|T¯+βτlog(1|Ω|∑j∈Ωe|uj|/τ)

T：目标点集合；Ω：排除目标邻域和源面近场的背景。
背景项是平滑最大值，τ 控制平滑程度。

反向 / 目标 → 复场 → 相位
dL=Re(gHdu)q=GHg ∇φL=Im(z¯⊙q)

等价于伴随系统

AHλ=gq=BHλ

实际迭代直接调用响应基 VJP；
无需逐相位差分，也无需每步重新求解 PDE。
